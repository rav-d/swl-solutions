# Video Background Assets

## Recommended Video Specifications

### File Formats
- **Primary**: MP4 (H.264 codec) - Best browser support
- **Secondary**: WebM (VP9 codec) - Better compression, modern browsers
- **Fallback**: MP4 (H.265/HEVC) - For newer devices

### Resolution & Quality
- **1080p (1920x1080)**: Desktop and large screens
- **720p (1280x720)**: Mobile and tablet devices
- **4K (3840x2160)**: Optional for high-end displays

### File Size Guidelines
- **1080p**: 5-15MB (10-30 seconds)
- **720p**: 2-8MB (10-30 seconds)
- **WebM**: 30-50% smaller than MP4

### Content Guidelines
- **Duration**: 10-30 seconds (will loop)
- **Aspect Ratio**: 16:9 (landscape)
- **Content**: Professional, relevant to your business
- **Motion**: Subtle, not distracting from text
- **Lighting**: Consistent, not too bright/dark

## File Naming Convention
```
hero-background-1080p.mp4
hero-background-720p.mp4
hero-background.webm
```

## Optimization Tools
- **HandBrake**: Free video compression
- **FFmpeg**: Command-line video processing
- **Online**: CloudConvert, Clipchamp

## Performance Tips
1. Use multiple resolutions for different devices
2. Compress videos to reduce file size
3. Consider using WebM for better compression
4. Test on various devices and connections
5. Provide fallback images for slow connections
